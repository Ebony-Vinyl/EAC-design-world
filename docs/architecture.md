# 制作架构与验收

## 一套工程，两种操作入口

```text
DeepSeek Harness 对话 / 中文模板选择 / 设置页
                       |
          原生工具与 MCP 工具目录
                       |
       项目持久化 + 修订历史 + 制作队列
                       |
       录制 -> 分析 -> 镜头表 -> 时间线
                       |
       旁白 + 音乐 + 字幕 + 渲染 + 检查
                       |
             MP4 + 工程 + 检查报告

```

项目聚焦 AI 自主剪辑。设置、制作任务与模板库在 Harness 中呈现；AI 通过统一工具修改时间线并输出可审查的工程。

## 完全自主制作的必要条件

1. **创意简报**：受众、渠道、时长、产品事实、素材来源、必须出现与不可出现的内容。
2. **真实观察**：产品录制必须有操作结果；用户素材先探测并观看。宣传片中不冒充存在未实现的功能。
3. **编导计划**：先明确每个镜头的作用、起止、画面动作、字幕、旁白与节拍，再生成画面或剪辑。
4. **同一时间基准**：素材、字幕、音乐、动作与转场共用秒制时间线，确定性动画支持任意帧重现。
5. **分阶段执行**：长操作进入队列，保存输入与错误。断电或进程重启不能被记为成功。
6. **独立验收**：技术检查与视觉、叙事检查分别记录；没有视觉评审时，不宣称艺术质量已经通过。
7. **持续精修**：同一工程支持人工改动。使用修订号拒绝陈旧写入，保留原素材与历史剪辑。

| --- | --- | --- |
| browser-use/video-use | 转录时间戳驱动剪辑、保留源素材 | 转录与删停顿建议、可修订时间线 |

## 内置模板

MG 的 15 套方案保留原源码、提示词、示例成片、配乐脚本与许可。经典和 v2 宣传片技能保留各自目录，不互相覆盖。选择模板不会自动改写用户的素材或品牌。

确定性渲染要求页面暴露 `renderAt(t)` 或 `__seek(t)`，并在字体就绪后设置 `__ready`。编码前检查同一时间点重复出图是否一致；运行异常与缺失资源记录在报告里。

为兼容 OpenDesign 的合成约定，模板也可以声明 `window.__timelines`（对象或数组，元素可含 `duration`/`seek`）与 `data-duration` 属性；渲染桥从中推导时长，并在缺少 `renderAt`/`__seek` 时回退到 `__timelines.*.seek(t)`，全部通过同一确定性 seek 逐帧出图。

## 设计库与成品

OpenDesign 内容由 `src/open-design-library.mjs` 索引（原始文件在 `vendor/open-design/`，受许可与来源记录约束）。后端提供只读的 `GET /api/library`、`POST /api/tools/library_read`，以及持久化的设计项目与成品：`POST /api/design/projects`、`POST /api/design/artifacts`、`GET /api/design/state`。成品是 HTML/SVG/Markdown 文本，按不可变修订保存，历史版本不被覆盖。

`GET /api/design/artifacts/:id/content|preview|download` 分别返回文本、沙箱预览与原文件。预览在不透明来源中运行（`sandbox` 且无 `allow-same-origin`，`connect-src 'none'`），第三方导入的 `vendor/open-design` HTML/SVG 同样套用该沙箱策略，无法共享应用来源或访问可写 API；经典本地模板预览不受影响。

只有含真实 HTML/SVG 源文件且运行时依赖可用的条目才可渲染。仅有提示词、示例或需要外部生成器（如 seedance/gpt-image）的条目在目录中标记为不可渲染，`render-template` 会给出明确错误而不是伪造成功；缺失的本地依赖与外部依赖在报告中如实记录。

设计模式的选择按会话持久化（`PUT/GET /api/composer`），仅对该会话追加设计上下文；模式本身不产生任何成品，只有真实调用 `design_project_create`/`design_artifact_save` 后才存在成品。

## 质量目标与后续工作

当前阶段验证执行正确性、工程可交接与真实桌面集成。要达到稳定商业交付，还需按题材建立可复现样片集，而非仅扩展工具数量。

- 产品片：镜头选取、品牌事实核查、真实录屏光标、定制动态排版、独立视觉审片与返修。
- 口播：更高质量 ASR、说话人分离、语义重录去重、字幕校对、配音质量评估。
- 风景与动漫：镜头语义检索、动作连续性、情绪节奏、人工样片盲评。（专业参数化调色已落地：`src/media/grading.mjs` 支持曲线/HSL 限定器二级/色相曲线/分区轮并烘焙为 `.cube` LUT；空间蒙版在原生渲染中处理，不能烘入单张全局 LUT，`grade-preview` 输出前后对比与统计护栏、`scopes` 输出波形/矢量示波器，见 [调色指南](grading.md)；`beats` 节拍分析驱动音乐卡点，`clip.speed`/`clip.motion` 支持变速与数字运镜；网络素材检索与下载见 `src/providers.mjs`。超过 10 个视觉片段的时间线自动分块多 Pass 渲染：先按批把片段渲染为工程尺寸中间片，再一次性合成、混音与烧字幕，避免数十个 4K 解码器同时驻留导致内存耗尽。）
- 音乐：音轨分离、用户曲目段落识别、节拍置信度、可配置专业语音与作曲服务。
- 批量：参数化模板、数据表、并发配额、输出去重、跨比例排版检查。

这些条目是明确的产品积累方向；首版界面与报告不将其伪装成已经实现。
