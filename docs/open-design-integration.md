# OpenDesign 融合记录

日期：2026-10-17。

本次融合保留 EAC 的 Node、FFmpeg、Playwright 和 Harness 插件结构，导入 OpenDesign 的内容库并接通设计工程、隔离预览、导出及原生右侧画布。没有把上游完整桌面应用嵌套在插件中。

## 已接入

- 152 套设计体系：说明、令牌、真实 CSS、字体栈、组件示例和预览资源。
- 517 个模板条目：188 个示例、115 个设计模板、63 个视频模板、45 个图片模板、58 个视频提示词、48 个图片提示词。
- 169 项创作技能、13 个基础组件、14 个场景，总计 865 个条目。另保留 EAC 原有 17 个视频选项。
- 正常、剪辑、Design 三种模式；Design 下有网站/原型、动效、幻灯片、文档、图片类型。
- 输入框下方推荐区与完整模板库；选择只写入草稿，不发送消息。正常→剪辑→正常→剪辑能恢复推荐。
- 会话模式、模板和设计体系保存，并按当前会话组装 AI 上下文；提供 `library_list`、`library_read`、设计工程和成品保存工具。
- 使用 Harness 官方 `sidebar.right.pane.tab` 注册 `eac-canvas` 页面；复用宿主分栏、停靠和全屏机制。没有会话侧栏存储时使用可关闭的临时面板。
- 视频输出、HTML 网页、HTML 幻灯片分页、SVG、Markdown 的作品画布，按版本保存与读取。
- HTML/SVG 实时预览、不可变修订、并发冲突保护、中文文件名下载。
- PDF、PNG 导出；HTML 幻灯片的 PPTX 整页图像导出，原 HTML 保留文字/图形编辑能力。
- 制作工作台的多轨时间线编辑：开始时间、素材入点、时长、音量、轨道、添加/删除和修订检查。
- 设置页工作台改用顶部导航；编辑器提供预览、源码、并排三种显示方式，窄面板默认预览。

## 视频运行适配

确定性渲染支持原有 `renderAt(t)` / `__seek(t)`、OpenDesign 的 `window.__timelines`（包括多个 GSAP 时间线）和 CSS 动画时间定位。渲染前暂停自动播放，保留同一时刻复现检查和 FFmpeg 技术质检。

已实际将 `od-vt-frame-bold-poster` 渲染为 2 秒、12fps、480×270 的 H.264 MP4：24 帧，确定性检查像素完全一致，无缺失素材，技术质检通过。它是模板原示例验证，不是按用户简报定制的交付视频。

源文件包含 `__VIDEO_SRC__` 等占位符或 `data-composition-src` 子合成的条目会标记依赖，不能直接被当成可用成片。远程 Seedance/Veo/图像模型与 HyperFrames Electron 子合成引擎没有整体搬入。
