# EAC design world v0.6.1

开发预览版。此版本是 0.6.0 的修复版本，重点修正时间线拖拽的真实缺陷，并同步上游 macOS 录制与转录兼容改动。

## 时间线拖拽修复

0.6.0 引入的轨道拖拽在真实使用中有四处缺陷，本版全部修正：

- **拖拽片段头部会累积素材入点**：每次指针移动都在当前值上再叠加一次绝对位移，把头部向右拖 10 步后素材入点从 1 秒漂到 1.99 秒（应为 1.18 秒），音画从此不同步。现在三种手势都只读手势开始时的快照值。
- **素材入点可被拖成负数**：向左拖头部没有下界，实测到过 -1.32 秒，保存时被服务端拒绝。现在下界取「开始时间」与「素材入点」中更严格的一个。
- **向右拖尾部可以超过素材长度**：没有上界，保存时同样被拒。现在按 `(素材时长 - 入点) / 变速` 封顶。
- **拖拽结束后页面会自动滚动**：拖拽结束触发了按钮的点击，把片段编辑器平滑滚动进视野，视图在刚拖完时就跳走，下一次手势落在错误位置。现在只有未移动过的点击才会滚动。

另外时间线总长原本每帧重算，片段变长会让同一像素位移对应更多秒，手势中途出现「加速」；现在在手势开始时冻结。

拖拽结果仍实时写回上方的数值输入框，保存以输入框数值为准，原有的精确输入方式没有被削弱。

## 其他修复

- **composer 高度断言修正**：`scripts/verify-open-design.mjs` 原断言直接比较 260px，但 fixture 的卡片是 `content-box`，加上内边距与边框后实际为 278px，脚本在本机任何时候都会失败。现按内容高度与实际盒模型断言。
- **删除死代码**：`src/engine.mjs` 里 `browserCandidates()` 未被任何路径使用（浏览器探测走 `src/browser.mjs`），已删除以避免两套逻辑分叉。

## 沿用 0.6.0 的改动

本版包含 0.6.0 之后合入的全部内容：

- macOS 桌面录制（avfoundation，自动发现屏幕设备索引、显式 `uyvy422`、Retina 宽度上限）。
- 转录默认模型改为用户数据目录下的 `models/faster-whisper-tiny`，不再硬编码作者本机路径；`scripts/transcribe.py` 同时兼容 PyAV 18/19 的 `metadata_errors` 签名。
- 强杀宿主后遗留写锁可立即接管（记录持有者 pid，实测 54ms 接管）。
- 插件不再对宿主 composer 施加 `!important` 高度覆盖，复用同一 composer 的其他插件可以正常输入。
- 空选择 + 正常模式的同步失败不再误报「选择未能同步」。

详见 [0.6.0 发布说明](release-v0.6.0.md) 与 [问题处理记录](issue-fixes-2026-11-08.md)。

## 安装文件

| 文件 | 内容 |
| --- | --- |
| `eac-design-world-v0.6.1-plugin.zip` | 插件源码、预构建界面、Shotcraft 视频和设计库，不含 Node 依赖 |
| `eac-design-world-v0.6.1-update.zip` | Ed25519 签名本地更新包，含 `manifest.json` 与相邻 `files/` |
| `eac-design-world-v0.6.1-media.zip` | 可选经典模板大媒体；与 0.3.0–0.6.0 的媒体内容一致，无需重复下载 |
| `eac-design-world-0.6.1.tgz` | npm / pnpm 可安装的运行包，资源首次启动时从包内还原，无 EAC 安装生命周期脚本 |
| `SHA256SUMS.txt`、`release-manifest.json` | 文件哈希、来源提交、签名及实际验证结果 |

从 GitHub 安装打包文件：

```sh
npm install https://github.com/Ebony-Vinyl/EAC-design-world/releases/download/v0.6.1/eac-design-world-0.6.1.tgz
```

也可直接从 npm 安装：`npm install eac-design-world@0.6.1`。

## 已有用户升级

0.3.0–0.6.0 的维护中心可检查签名 `updates` 通道，也可下载本版 update ZIP，完整解压后选择其中 `manifest.json`。更新完成后核对运行版本和磁盘版本均为 0.6.1，按提示刷新宿主界面。升级前先结束制作任务。

更新保留 `.eac` 项目与设计文件、配置、已有依赖、可选媒体与用户自备动效库，并保留更新前备份供回滚。

## 验证与限制

发布附带的 `release-manifest.json` 记录本轮实际执行的测试、生产构建与打包结果；不会以格式检查冒充目标商业软件验收。

剪映、Premiere、Resolve 导出进行了格式和时序回归验证，实际软件版本的导入兼容性仍需在目标 NLE 确认。运动效果、蒙版几何和成片润色在交换格式中需要人工重建。参数化 LUT 不等于 HDR / ACES / 完整色彩管理。网络素材可用性、服务凭据和许可由提供方决定。
