# Harness 中的 AI 视频制作

插件通过官方 `dsh.bundle.patch` 与客户端模块接口加载。
后端在本机 `127.0.0.1:4173` 运行，拥有统一的项目、素材和制作队列。
宿主原生工具和 MCP 服务调用同一个后端。

## 使用入口

- 设置页：`EAC design world`，包含制作工作台、素材、任务、模板和制作环境配置。
- 输入框底栏左侧：`创作模式` 向上展开，包含正常模式、剪辑模式，以及暂不可选的 `Design 模式 · 即将推出`。
- 剪辑模式右侧显示 `选择模板`。点击打开居中模板库，搜索、分类、预览并选择 15 套 MG 与经典/v2 产品片模板；选中成功后弹窗自动关闭，按钮显示所选名称。正常模式隐藏模板按钮。
- 空白会话且草稿为空时，在输入框下方显示 4 张模板推荐，可收起或点击“浏览全部”打开模板库。开始输入后推荐区收起。推荐区通过插件所属输入框旁的局部 portal 挂载，并随会话切换卸载；不占用宿主统计栏。
- 尚未选择工作区、没有会话的惰性首页不渲染宿主输入扩展槽位，因此该状态暂不显示插件控件；选择工作区进入可编辑会话后显示。
- 选择结果经官方输入接口加入草稿；保留原有文字，绝不自动发送消息。模式与模板展示状态按会话保存，切换模式不会删除草稿中的文字。
- 弹窗支持关闭按钮、遮罩点击及 Escape；模板服务连接失败时可重新加载。

## 工具

工具名称统一以 `eac_` 开头：

`status`、`project_create`、`project_get`、`asset_import`、`timeline_plan`、
`timeline_update`、`job_submit`、`job_status`、`job_cancel`、`template_read`、
`library_read`、`design_project_create`、`design_artifact_save`、`design_state`。

这些工具让宿主 AI 读取素材、录制真实产品、制定镜头表、编辑时间线、
生成旁白和配乐、转录字幕、渲染并检查成片。任务类型及参数由工具说明声明。
长任务返回 ID，AI 必须继续查询终态与检查真实输出。

设计相关工具读取 OpenDesign 库（`library_read`）、建立持久设计项目
（`design_project_create`）、按不可变修订保存 HTML/SVG/Markdown 成品
（`design_artifact_save`）并读取状态（`design_state`）。仅切换到设计模式不产生任何成品；
草稿里的模板/设计系统标记是参考数据，用户需求优先。库条目的运行时依赖可能缺失，
必须如实报告而不是宣称已生成。

## 编辑保护

时间线更新要求当前修订号。后台口播初剪遇到人工修改时保留转录结果、
拒绝覆盖时间线。原素材保留，项目保存历史剪辑快照。
服务关闭会取消任务并等待实际工作进程停止；进程意外中断在下次启动时标为失败。

## 真实质量检查

技术检查验证解码、时长、音量、黑场与静帧。字幕在实际剪辑后的时间线上重新映射，
通过 ASS 烧录。构图、叙事、品牌事实和字幕内容需由有视觉能力的宿主 AI 审查。
输出成功不等于艺术评价通过。

## 安装与回滚

`scripts/install-harness.mjs` 为本地开发安装保留原始 profile 文件备份。
已安装插件可通过官方插件管理器启用，检查其 `application: applied` 和
`fiberPhase: active`。替换 Host JavaScript 后需重启宿主，单纯刷新网页不足以换代。
安装过程中不修改其他插件配置或发送用户消息。
