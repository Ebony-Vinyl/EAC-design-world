# 插件内置制作能力与验证边界

EAC 的剪辑、调色、示波器与工程导出在插件自身执行，依赖本地 FFmpeg/FFprobe，不依赖安装 DaVinci Resolve 或 Adobe Premiere。工程导出是为人工接手续剪提供交换文件，不代表插件包含这两款软件的全部能力。

## 已有的原生能力

| 工作环节 | 插件内能力 | 使用边界 |
| --- | --- | --- |
| 素材 | 本地媒体导入、真实浏览器/桌面录制、网络视频/配乐搜索下载、来源与许可记录 | 网络素材源的可用性、许可与 API 凭据取决于提供方 |
| 剪辑 | 精确片段起止、源入点、轨道合成、恒定变速、数字推拉平移、字幕与节拍分析 | 多段恒定变速不能当作连续速度曲线；数字运镜不能替代拍摄时的真实相机运动 |
| 基础调色 | 项目 look、片段覆盖、曝光/白平衡/对比/饱和/自然饱和、lift/gamma/gain、offset | 风格预设只提供起点，不能自动识别或还原相机 Log 编码 |
| 高级调色 | RGB/主曲线、色相曲线、亮度饱和曲线、阴影/中间调/高光分区、HSL 限定器、静态局部蒙版 | 不是 Resolve 节点图、Magic Mask 或动态跟踪；空间蒙版不能写入单张全局 LUT |
| 色彩转换 | 外部 `.cube` 相机输入 LUT、风格 LUT、参数化 LUT | 官方 LUT 必须匹配机型、记录曲线与目标色域；不等同于完整 ACES/RCM/OCIO 场景线性色彩管理 |
| 评估与迭代 | 调色前后对比、亮度与饱和统计、波形/矢量示波器、非破坏性调色版本、曝光匹配建议 | 数值护栏不等于艺术评分；镜头匹配建议不能代替肤色、白平衡和视觉审片 |
| 成片 | 配乐/旁白/源音混合、音量归一、淡入淡出、锐化、暗角、柔光与分批渲染 | 不是 Fairlight 多总线调音台或完整视频特效合成器 |
| 人工续剪 | 剪映草稿、Premiere/Resolve 可导入的 FCP7 XML、SRT、LUT 与交接说明 | 不生成原生 `.prproj` 或 `.drp`；交换格式无法保留的效果需重建，以每次导出清单为准 |

## 尚未实现的软件级能力

当前不能宣称覆盖 DaVinci Resolve 或 Premiere 的所有功能。尚未实现的主要领域包括完整节点图与 Fusion 合成、目标跟踪与自动抠像、光流插帧与连续速度曲线、专业时空降噪、完整 HDR/广色域色彩管理与母版输出、多机位同步与切换、代理/在线重连工作流、嵌套序列、完整关键帧曲线编辑、Fairlight 级音频路由与插件、完整字幕包装、第三方插件生态和协作项目管理。

这些领域需要各自的处理引擎、数据模型、AI 工具接口、可视化控制和真实素材验收；仅增加参数名称或调用接口不构成功能实现。

## 验收方式

自动测试需要覆盖真实像素变化、音频与字幕时序、异常与取消、工程结构和文件可下载性。浏览器验收应通过真实按钮产生任务与输出。对工程格式的结构验证不能替代在对应商业剪辑软件里实际导入的兼容性验证。任何未经实际软件导入的格式都应说明这一限制。

专业调色的视觉质量依赖原始素材质量、正确的输入转换、可靠的显示环境和具体审美目标。项目不使用“达到达芬奇专业人士水平”的无依据评分；交付以具体素材的对比图、示波器、导出文件和已执行的验证记录为依据。
