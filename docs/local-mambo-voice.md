# 本地曼波中文配音

## 范围与决定

- 使用用户确认的 GPT-SoVITS v2 音色基准，以配置中的模型、中文参考音频、前处理和种子复现。
- 复用工作台 `voice` 任务与 `produce` 流程；本机默认音色保存为 `mambo-zh`。
- 单用户本地排队执行，按任务启动 Python 子进程。以已有短句测试约十几秒的启动和合成速度为基准，不承诺实时变声。
- 配音文本和推理均留在本机；首次安装从固定公开地址下载模型和运行依赖，生成阶段不调用云端语音接口。
- 选择曼波后配置缺失、哈希不符或推理失败均明确报错；不自动切换系统声音。
- 保留取消、超时和临时文件清理，成功后才发布输出；模型与样音不放入源码仓库。

已选择逐任务子进程，避免额外常驻服务和端口维护。相比常驻模型服务会增加冷启动耗时，但沿用现有队列、取消和文件发布机制，适合当前本地工作台。跨平台接入使用显式 Python 路径；Windows 的真实 GPT-SoVITS 环境需另行验收。

## 音频模板与本地下载

顶部“视觉模板”右侧新增“音频模板”，也可访问 `/?view=audio`。

- **默认音色**：使用 macOS say / Windows SAPI，无需下载；可试听和设为默认。
- **曼波中文**：未安装时显示“下载到本地”。需要先安装 Python 3.12，并保证 FFmpeg / FFprobe 可用。自动发现 `python3.12`、`python3`、`python` 或 Windows `py -3.12`，也可用 `EAC_GPT_SOVITS_PYTHON` 指定解释器的绝对路径。
- 模型及固定引擎包约 1.07 GB，Python 依赖另计；需要额外安装和缓存空间。优先使用已有 `uv`，否则使用 `venv` / `pip` 创建独立环境。
- 下载显示资源进度，支持取消、重试和服务端支持范围请求时的断点续传；已完成的资源通过 SHA-256 校验后复用。依赖安装及首次试听使用阶段状态，不将其冒充文件下载百分比。
- 资源保存在用户数据目录的 `voice/downloads/mambo-v1`，运行环境和模型安装到 `voice/mambo`。所有资源校验和首次真实合成通过后，才原子发布 `voice/gpt-sovits.json`，页面显示“已下载到本地”。
- 下载完成后点击“设为默认”，沿用设置中的 `ttsVoice`；下载本身不会修改默认音色。切换音色只影响后续任务，已有项目音轨保留。
- 安装失败不会发布未验证配置；已存在且无法识别的手动安装目录不会被覆盖。手动配置有效时直接显示已安装。

下载清单固定在 `src/mambo-preset.json`，HTTP 请求不能指定下载地址、安装路径或命令。来源为 [GPT-SoVITS 固定提交](https://github.com/RVC-Boss/GPT-SoVITS/tree/d7c2210da8c013e81a94bfc7b811a477c99fd506)、[MamboTTS v1.2.1](https://github.com/Tsukimisaka/MamboTTS/releases/tag/v1.2.1) 和 [预训练模型固定版本](https://huggingface.co/lj1995/GPT-SoVITS/tree/8f8857563c040d542de108a2c18b0425abd6c9c5)。模型和生成音频不随源码发布。

## 本机配置

默认读取用户数据目录中的 `voice/gpt-sovits.json`，可用 `EAC_GPT_SOVITS_CONFIG` 指定另一份本地配置。

```json
{
  "pythonExecutable": "/absolute/path/to/venv/bin/python",
  "engineRoot": "/absolute/path/to/GPT-SoVITS",
  "voiceRoot": "/absolute/path/to/voice-assets",
  "profilePath": "/absolute/path/to/voice-assets/voice-anchor/voice-profile.json",
  "profileSha256": "填写已确认 voice-profile.json 的 64 位 SHA-256"
}
```

Windows 使用对应环境的 `Scripts/python.exe`。前四个字段都必须是绝对路径，`profileSha256` 固定整份基准配置，防止参考文本、种子或参数被无意修改。配置只由本地文件提供，不通过任务请求指定可执行文件或脚本。Python 需要 3.11+，本机验收使用 3.12。

`voice-profile.json` 采用已锚定的 schema 1，包含已确认音色 ID `mambo-gpt-sovits-v1`、模型及前处理文件的 SHA-256、参考音频及其文本、推理参数、引擎版本。生成前会检查清单和文件哈希。配置中的路径与模型需要持续保留。

通过音频模板下载并设为默认，或手动安装引擎和模型后，将工作台设置中的“旁白声音”选择为“曼波中文”，保存即可作为后续旁白任务的默认值。没有安装模型的其他电脑继续使用各自的语音设置。

## 验证与维护

通过工作台新建独立测试项目，输入新文案并点击“生成旁白”。确认任务完成、项目音轨更新，浏览器能播放和下载音频，再导出包含旁白的成片。

模型更换或前处理修改后需重新试听确认，并更新基准清单；不应绕过哈希检查。需要恢复系统旁白时清空 `ttsVoice`，或填写已安装的系统声线名称。项目中已生成的音轨保留。
