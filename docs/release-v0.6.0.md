# EAC design world v0.6.0

开发预览版。此版本加入素材检索、参数化调色、变速运镜和人工续剪工程导出，并修复本地审查发现的凭据、像素、预览和交接问题。

## 制作与审查修复

- 素材服务凭据只保存在本地，状态接口、原生 AI 工具与 MCP 不再返回明文。设置页可保留、更换或明确清空密钥。
- 柔光在 RGB 空间中合成，避免 YUV 色度参与 Screen 运算导致灰色变紫。
- 调色预览按项目画布比例输出，原始侧与调色侧使用相同运镜和构图。高光/暗部护栏逐帧对照，避免已有裁切掩盖另一个镜头的新问题。
- 调色控件展示预设与项目继承后的有效值，区分继承和显式覆盖。
- Shotcraft 素材可通过原生工具、HTTP 与标准 MCP 按模板 ID 导入。
- 剪映草稿和 FCP7 XML 保留循环配乐，XML 补齐音频速度和音量，并按轨内重叠拆轨；NTSC 素材保留正确的时基。
- LUT 交接区分基础分支和窗口分支，避免重复调色；交接清单记录片段与窗口映射及几何参数，供人工重建。
- 长项目名的剪映草稿仍带唯一标识；更换配乐同步移除旧音乐署名。
- 新增本地 MCP 启动入口、macOS / Windows 浏览器发现和系统配音；保留上游 FFmpeg 兼容、预览隔离与数据并发修复。

## 安装文件

| 文件 | 内容 |
| --- | --- |
| `eac-design-world-v0.6.0-plugin.zip` | 插件源码、预构建界面、Shotcraft 视频和设计库，不含 Node 依赖 |
| `eac-design-world-v0.6.0-update.zip` | Ed25519 签名本地更新包，含 `manifest.json` 与相邻 `files/` |
| `eac-design-world-v0.6.0-media.zip` | 可选经典模板大媒体；与 0.3.0–0.5.0 的媒体内容一致，无需重复下载 |
| `eac-design-world-0.6.0.tgz` | npm / pnpm 可安装的运行包，资源首次启动时从包内还原，无 EAC 安装生命周期脚本 |
| `SHA256SUMS.txt`、`release-manifest.json` | 文件哈希、来源提交、签名及实际验证结果 |

从 GitHub 安装打包文件：

```sh
npm install https://github.com/Ebony-Vinyl/EAC-design-world/releases/download/v0.6.0/eac-design-world-0.6.0.tgz
```

npm 公共注册表是否已有同版本应以注册表查询为准；GitHub 上的 `.tgz` 可直接安装。

## 已有用户升级

0.3.0、0.4.0、0.5.0 的维护中心可检查签名 `updates` 通道，也可下载本版 update ZIP，完整解压后选择其中 `manifest.json`。更新完成后核对运行版本和磁盘版本均为 0.6.0，按提示刷新宿主界面。升级前先结束制作任务。

更新保留 `.eac` 项目与设计文件、配置、已有依赖、可选媒体与用户自备动效库，并保留更新前备份供回滚。全新安装的锁文件同时更新了已知漏洞依赖；原地更新保留旧依赖，需要刷新这些依赖的用户可在关闭旧服务后额外运行 `npm ci --omit=dev`。新增目录锁及依赖随更新文件独立捆绑，旧安装无需先补装新依赖即可启动。异常结束留下的目录锁在心跳超时后自动恢复，不能在进程仍运行时手动删锁。

npm/pnpm 安装的 0.3.0–0.5.0 存在旧热重载缓存限制，若维护中心更新因运行版本不一致而回滚，先停止旧 EAC 服务，从本版插件 ZIP 解压的目录运行新进程签名更新：

```sh
node scripts/update-local.mjs --install "/旧安装真实路径/eac-design-world" --data-dir "/原数据目录" --manifest "/已解压更新包/manifest.json" --stopped
```

`--install` 和 `--data-dir` 使用维护中心显示的真实路径；命令从新解压的 v0.6.0 目录运行。它校验原有签名、公钥与哈希，保留数据及备份；完成后重新启动原安装。需要回滚时，同样停服后运行上述命令并用 `--rollback` 替代 `--manifest`。0.6.0 已修复后续 npm/pnpm 安装的热重载缓存选择。

0.1.0 没有维护中心：备份原安装目录，关闭旧 EAC 服务，将本版插件文件合并到原目录，保留 `.eac`、`node_modules` 和可选媒体，再重新加载 Harness；也可从本版包安装到新位置并显式继续使用原数据目录。不要删除项目数据或同时启动两个写入同一数据目录的服务。

## 验证与限制

发布附带的 `release-manifest.json` 记录本轮实际执行的完整测试、生产构建、旧版安装升级及回滚结果；不会以格式检查冒充目标商业软件验收。

剪映、Premiere、Resolve 导出进行了格式和时序回归验证，实际软件版本的导入兼容性仍需在目标 NLE 确认。运动效果、蒙版几何和成片润色在交换格式中需要人工重建，按每次交接说明操作。参数化 LUT 不等于 HDR / ACES / 完整色彩管理。网络素材可用性、服务凭据和许可由提供方决定。
