审查日期：2026-10-17。

基线为唯一的本地提交 `a5bee34`，另将开始审查时已有的未提交改动作为当前实现检查。没有撤销既有修改，也没有创建提交。

范围包括第一方前端、设计成品存储与导出、HTTP 文件服务、插件与维护更新链路，以及相关自动化测试。第三方 vendor 内容仅检查集成与访问边界，没有逐行审计整个上游源码。

## 已修复的问题

### 1. P1：更新回滚可能导致用户文件被删除

位置：`src/maintenance-updater.mjs` 的备份、恢复和 `rollback()`。

原实现将备份中的完整文件清单 `preimage` 当作更新器拥有的文件清单。用户自建文件也因此被标记为可管理文件，下一次更新可能将它删除。恢复过程还会删除备份后新增、但并非由更新安装的文件。

现在备份分别记录原有所有权 `owned` 和本次将安装的文件 `installed`。回滚恢复原有所有权，仅清除新版本实际引入的文件，保留用户后续创建的文件。旧备份缺少所有权时采用空所有权，避免凭完整快照推定删除权限。

新增回归覆盖：更新 → 新增用户文件 → 回滚 → 再次更新；同时确认旧版本文件恢复、新版本独有文件清除、用户文件保留。此问题来自审查前已有的未提交维护功能。

### 2. P1：输出 HTML 可以以工作台同源权限调用写入 API

位置：`src/server.mjs` 的 `/api/files`。

原实现允许输出目录内的 HTML 内联执行，但没有应用第三方预览使用的安全策略。实际浏览器探针可通过该 HTML 创建设计项目。

现在 HTML、HTM、SVG 通过不透明来源的 sandbox CSP 提供，并限制网络连接；普通音视频仍保留字节范围读取。新增浏览器回归确认脚本无法写入 API，项目数量保持不变。此问题存在于 `a5bee34`。

### 3. P1：切换文件时，较慢的读取可能覆盖新文件的编辑状态

位置：`ui/DesignWorkspace.jsx` 的 `EditorPanel`。

原实现没有区分先后发出的内容请求。快速切换两个文件后，旧请求仍可能更新当前编辑器内容、修订号，并影响后续保存。

现在用请求序号和文件加载标识约束内容更新；读取未完成时禁用编辑及保存。导出结果同样不会在切换文件后显示为另一文件的结果。

浏览器测试主动拦住首个文件的响应，在第二个文件加载完成后才释放，验证旧响应被忽略。此问题存在于 `a5bee34`。

### 4. P1：编辑文件名可能误写另一个同名成品

位置：`ui/DesignWorkspace.jsx` 的保存流程。

后端按项目与文件名定位成品。原编辑器允许修改文件名，却继续携带原文件修订号；当目标文件恰好具有同一修订号时，会向目标文件追加错误内容。改成一个不存在的名称则会被已有修订号校验拒绝。

现在同名冲突会直接提示；更名保存明确显示“另存为新文件”，创建独立成品并保留原文件。浏览器测试验证冲突被阻止，另存成功且两个原文件的修订号不变。此问题存在于 `a5bee34`。

### 5. P2：离开编辑视图会丢失未保存草稿

位置：`ui/DesignWorkspace.jsx`。

草稿现在按项目、文件独立保留，内存立即记录编辑，浏览器会话存储延迟写入，并在离开、刷新时补写。保存成功会清除相应草稿。历史版本切换在有未保存编辑时禁用，避免覆盖草稿。

已验证文件切换、工作区切换、页面刷新后的草稿恢复。浏览器存储被禁用或容量不足时只能保证当前页面生命周期内的内存保留；会话存储不代替正式保存或跨设备同步。

### 6. P2：工作台预览始终显示固定宣传片

位置：`ui/main.jsx` 的 `Preview`。

原预览固定读取 `/media/studio-preview.mp4`，没有使用当前项目的 `lastOutput`。项目渲染完成后仍无法在该区域查看实际成片。

现在优先展示当前项目成片，支持“项目成片 / 所选模板”切换；未渲染时展示所选模板真实缩略图和预览入口，播放器错误也有明确反馈。此问题存在于 `a5bee34`。

### 7. P2：导出丢失相对路径资源

位置：`src/design-export.mjs`。

原实现通过 `page.setContent()` 在 `about:blank` 上渲染，`/vendor/...` 等资源无法解析为本地服务 URL，生成文件却仍报告成功。

现在在本地来源下提供独立的渲染文档 URL，保持现有 vendor 资源白名单，禁止访问 API，并阻止 Service Worker 绕过路由控制。回归测试记录真实资源请求，确认相对图片被加载而 API 请求未到达服务。此问题存在于 `a5bee34`。

### 8. P2：本地导入不接受清单构建器的默认目录结构

位置：`src/maintenance-updater.mjs` 的 `resolveLocalPackageRoot()`。

构建器默认生成 `feed/manifest.json` 并使用 `../` 作为文件基址，导入器却一概拒绝父目录基址。

现在仅对规范的 `feed/manifest.json` 与精确的 `../` 组合允许解析到包根目录，并检查目录符号链接。其他父目录跳转仍被拒绝。新增回滚回归直接使用构建器默认输出完成导入，原有越界与 junction 测试仍保留。此问题来自审查前已有的未提交维护功能。

### 9. P2：设计弹窗缺少一致的键盘与焦点行为

位置：新增的 `ui/Dialog.jsx`，及工作台、模板预览和设计工作区的调用处。

统一 Escape 关闭、Tab 循环、弹窗显示期间的页面滚动锁定、关闭后焦点返回。仅最上层弹窗响应 Escape，保留嵌入式模板库的内外层关闭顺序。焦点返回在子输入框自动聚焦之前记录触发元素。

### 10. P2：画布筛选与模板页码可能保留失效选择

位置：`ui/DesignWorkspace.jsx` 的 `DesignCanvas`、`ui/TemplatePickerGallery.jsx`。

画布的当前预览现在始终来自当前筛选结果；模板目录缩小后将页码限制到有效范围。搜索无结果时增加清除筛选入口，结果数量通过可访问状态区域反馈。
